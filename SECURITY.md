# Security

anynear is in beta and has not been independently audited. Reports of security problems are very welcome.

## Reporting a vulnerability

Please write to **security@anynear.app**, in English or German. Do not open a public issue or pull request for a
vulnerability.

In your report, describe:

- what you observed and why you think it is a security problem,
- how it can be reproduced (steps, browser and version, the version shown in the web app).

Please do not include other people's data, invitation links or backup files. If an example is needed, create it with
your own test devices and circles.

## What happens next

We confirm that we received your report and look into it. Please give us time to fix the problem before you publish
details.

## Rules for testing

- Test only with your own devices and circles.
- Do not disturb the operation of the anynear network (relays and services), and do not access data that is not yours.

## Recognition

There is no bug bounty. If you wish, we name you when the fix is published.

## Background

The procedures anynear uses and their known limits are described at https://anynear.app/en/technology/.
